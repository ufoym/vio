Fast

Faster than libjpeg-turbo on every CPU we measured, with and without SIMD. PNG decoding runs 2.2–3.6× libpng, and ahead of image-png, the fastest decoder measured, on 12 of 13 runners.

Complete

Sequential, progressive, arithmetic-coded and lossless JPEG at 2- to 16-bit precision, lossless transforms, APNG, every PNG chunk and transformation.

Portable

x86 MMX→AVX2, Arm NEON, PowerPC AltiVec, Loongson MMI and RISC-V Vector — one source, kernels selected at run time, no assembler needed.

Header-only

No build step and no zlib. Add include/ to your path or link the vio::vio CMake target, and include just the codecs you use.

    Formats

    Six formats, one tiny dependency graph.

    Each codec is a header that needs only vio/core.hpp. Packed-pixel readers and writers share vio::ImageReader<T> / ImageWriter<T> over 8-, 12- and 16-bit samples.

    vio/jpeg.hpp

    JPEG

    • Baseline, extended, progressive, arithmetic-coded, lossless
    • 8- and 12-bit lossy, 2- to 16-bit lossless
    • Rotate, flip, crop, wipe, drop and roll — losslessly
    • Scaled and partial decoding, raw planar YCbCr
    • ICC profiles, saved markers, quantization & dithering
    vio/png.hpp

    PNG & APNG

    • All color types, bit depths and Adam7 interlacing
    • Built-in SIMD inflate, deflate, CRC-32, Adler-32
    • Single-pass fast encoder, or zlib mode with byte-identical files
    • Progressive (push) decoding, read & write transformations
    • Passes the reference library's own test suite, bit for bit

    SIMD everywhere

    Written once. Tuned for every ISA.

    Kernels are written against a small vector interface and instantiated per back end. At start-up vio detects the CPU and dispatches each function to the best kernel; JSIMD_* environment variables cap the level.

    Quick start

    Zero to decoded in a dozen lines.

    Add the include path or pull it in with CMake. The JPEG API follows the classic scanline model; PNG offers whole-image codecs plus row readers, streaming and format conversion.

    • Throws vio::Error on malformed input
    • Disable SIMD at build time with VIO_NO_SIMD
    • Works with GCC, Clang, Apple Clang, MSVC and clang-cl
    include(FetchContent)
FetchContent_Declare(vio
  GIT_REPOSITORY https://github.com/ufoym/vio.git
  GIT_TAG        main)
FetchContent_MakeAvailable(vio)

add_executable(app main.cpp)
target_link_libraries(app PRIVATE vio::vio)   # header-only, C++20
    #include <vio/jpeg.hpp>

// file: std::vector<std::uint8_t> holding the .jpg
vio::jpeg::Decoder dec(file);
dec.set_output_color(vio::ColorSpace::RGB)
   .set_scale(1, 2);                       // half size, straight from the DCT
dec.start();

std::size_t stride = std::size_t(dec.output_width()) * 3;
std::vector<std::uint8_t> rgb(stride * dec.output_height());
while (dec.output_scanline() < dec.output_height()) {
  std::uint8_t* row = &rgb[dec.output_scanline() * stride];
  dec.read_scanlines(&row, 1);
}
dec.finish();
    #include <vio/jpeg.hpp>

vio::jpeg::Encoder enc;
enc.set_image(width, height, 3, vio::ColorSpace::RGB)
   .set_quality(90)
   .set_progressive();                     // or set_arithmetic(true), set_lossless(1, 0)
enc.start();

while (enc.next_scanline() < height) {
  std::uint8_t* row = &rgb[std::size_t(enc.next_scanline()) * width * 3];
  enc.write_scanlines(&row, 1);
}
std::vector<std::uint8_t> jpg = enc.finish();
    #include <vio/png.hpp>

// Decode: checks every CRC-32 and the Adler-32.
vio::png::Decoder dec;
dec.decode(file);
auto [w, h] = std::pair(dec.header.width, dec.header.height);
std::span<std::uint8_t> pixels = dec.pixels();   // native layout

// Encode: single-pass SIMD fast mode by default.
vio::png::Encoder enc;
enc.header = {w, h, 8, vio::png::kTruecolorAlpha};
std::vector<std::uint8_t> png = enc.encode(rgba.data(), w * 4);

// Or zlib mode, with files byte for byte like libpng's:
